# Release Notes

## 0.0.1 (Initial scaffold)

### What's new
- Initial project scaffold with Expo Router + React Native + TypeScript
- Login screen with server configuration
- Email inbox (IMAP, mock) with folder navigation
- Email detail view with reply, forward, and delete actions
- Compose new email with To / Cc / Bcc / Subject / Body
- Calendar view with monthly grid and event creation
- Tasks view with filter (active / all / completed) and task creation
- Contacts view with search and contact creation
- Settings screen with account info, toggles, and sign out
- CalDAV service interface (calendar events + tasks / VTODO)
- CardDAV service interface (contacts)
- IMAP / SMTP service interface
- Zustand stores for auth, email, calendar, tasks, and contacts
- Light + dark theme support
- GitHub issue templates (bug, feature, auth, email, calendar, contacts, tasks)
- EAS Build configuration for Android (APK) and iOS (IPA)
